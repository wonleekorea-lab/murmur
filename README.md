# journaling（MVP）

だらだら喋った今日を、**構造化した要点**と**ほぼそのままの行**に変えて積んでいく音声日記。
名前は目的そのまま。ホーム画面では `journaling`。

**記録に徹する。**解釈（洞察・問い・要約）は置かない。
喋ったものは母岩で、読みたいのはその中に走っている筋 — という見方はロゴに残してある。
リポジトリ名も `vein` のまま（変えると URL が変わり、ホーム画面に追加済みのアイコンが切れる）。

画面は横に2面だけ。**左＝話す／右＝記録**。

| 面 | やること |
|---|---|
| 左（既定） | 語が動きまわる中の **アメーバ** を押す → キーボードの🎤で喋る → `keep` |
| 左の**語を押す** | その語の問いが下に出る（押すまでは出ない） |
| 左を**上へなぞる** | **深い問い**が出る。なぞるたびに次。**下へなぞる**と ◯ に戻る |
| 右 | **日ごとの帯**。1日を24時間の1本にして、書いた時刻に点を置く。上に **#タグ** が溜まる（押すと絞り込み） |
| 右・点か行を押す | その日記がひらく（要点／全行／raw）。`keep` で日記として並ぶ |
| 右上の `▢` | 日記を全部、読める文にしてクリップボードへ。1件の右上・各段の右上にも `▢` がある |
| 右上の `···` | 設定（全部うつす・データの置き場所）。日記の並びの中には設定を置かない |

**触るのは真ん中のアメーバひとつだけ。** 語は触れない（動いているものを狙わせない）。

---

## 左の面で起きていること

**操作は2つだけ。語を押す。丸を押す。**（と、上下になぞる）

| | |
|---|---|
| 語が回る | 11語が、語ごとに違う楕円・違う速さ・違う向きで漂う。中心そのものもゆっくり流れるので、同じ道を二度通らない |
| 語が入れ替わる | 6.8秒ごとに1語が消え、置いていない語に替わる（32語の中から）。**押して選んでいる語は入れ替わらない** |
| 問いは押したときだけ | **語を押すと、その語の問いが下に出る。**押すまでは何も出ない。もう一度押すと外れて消える |

`do` `be` `have` … は日記の入り口になる概念。

**問いは勝手に入れ替わらない。**以前は4.6秒ごとに焦点が移って問いも書き替わっていたが、
読む先が定まらず、混乱するのでやめた。いま出ている問いは、自分で押したものだけ。

語を選んでいるあいだは、**場の動きが35%に落ちる**（止めはしない）。選んだ語は濃くなり、
その語のまま丸を押せば、その語が日記の入口（`seed`）として残る。

語同士が重なると読めないので、画面上で近づいたものだけ、そっと押し合わせている
（角度で測ると、楕円が近いところでの重なりを取りこぼす）。近いほど強く、遠いところでは
効かせないので、急に飛ばない。実測で、どこか1組でも字が重なっている瞬間は 1.7%。

### 深い問いの層

語の野は「**今日なにを喋るか**」の入口。こちらは「**人生のどこを掘るか**」の入口。

**指を上へなぞる**と開き、**なぞるたびに次の問い**が出る。**指を下へなぞる**と ◯ に戻る。
しきいは44px（取りこぼすと「反応しない」に見えるので低め）。縦の動きが横より大きいときだけ拾う。
開いているあいだ、語は押せない（押せるのは真ん中の丸だけ）。

- 開くと、語は引っ込み、**丸は下へ降りて小さくなる**。そのまま押せば、その問いで喋り始められる
- 押した問いは日記に残る（`ask`）。1件の面の頭と、記録の一覧と、写した文にも出る。
  入口の語（`seed`）には、問いの分類（`mortality` `control` `view` …）が入る
- **180問・45系統**（1系統4問）。いくら巡っても似た問いが続かないように配る（下記）

問いはストア派の日記の型を軸に、実存・仏教・儒家・アリストテレス・ニーチェ・
エピクロス・道家・カント・正義論まで45の系統へ広げ、**このアプリのために書き下ろした**もの。
`Journal Like a Stoic` の系譜だが、文言は引き写していない。

### 似た問いが出ないようにする

問いが増えても、配り方が雑だと「また同じようなことを訊かれた」になる。3つで防いでいる。

| | やり方 |
|---|---|
| 系統を寄せない | 束を作るとき、**45系統を1巡ずつ**配る。系統の並びは束のあいだ固定（巡ごとに混ぜ直すと境目で同じ系統が隣り合う） |
| 巡の境目 | 束を作り直すとき、**直前に出した問いは後ろへ回し**、直前4問と系統がぶつかる位置は入れ替える |
| 端末が覚える | 出した問いは `settings.seen` に残る。**閉じて開き直しても、180問を配り切るまで同じ問いは出ない**。配り切ったら、前の巡の順番（`prev`）を見て、いちばん長く待っている問いから配り直す |

書き出しの段で、似た問いが混ざっていないことも機械で確かめてある
（2文字ずつに割った重なりが4割を超える組が **0**）。

配り方は1800回（10巡ぶん）まわして実測した。

| 見たもの | 結果 |
|---|---|
| 同じ系統が連続した回数 | **0 / 1800** |
| 同じ系統が戻るまでの最短 | **4問**（ふつうは45問） |
| 同じ問いが戻るまでの最短 | **136問**（ふつうは180問） |

| 分類 | 問いの例 |
|---|---|
| `mortality` | 今日が最後の一日だと分かっていたら、予定のどれを消す？ |
| `control` | いま気を揉んでいることのうち、自分の手で動かせるのはどこまで？ |
| `view` | 100年後の人がこの1年を見たら、何を重要だと言う？ |
| `judgment` | 事実と、自分の解釈を分けると、何が残る？ |
| `praise` | 誰にどう思われたくて、それをやっている？ |
| `fear` | できないと決めているのは、試したからか、聞いただけか？ |
| `recurrence` | この1日を永遠に繰り返すとしたら、どこを変える？ |
| `absurd` | 意味がないと分かっていても、続けたいことは？ |
| `attachment` | 「これが無いと自分じゃない」と思っているものは？ |
| `universal` | 全員が同じことをしたら、世界はどうなる？ |
| `effortless` | 力を抜いたら、うまくいったことは？ |
| `story` | 自分についてよく話す物語は何？それは本当？ |

答えは置かない。**問いだけ置いて、あとは喋らせる。**

### アメーバ

真ん中は円ではない。9点の半径がそれぞれ違う周期で伸び縮みする閉じた曲線を、
Catmull-Rom でつないで毎フレーム描き直している。**平らな墨1色**で、
グラデーション・影・広がる輪は使わない。生きている感じは、輪郭の歪みだけで出す。

動かさない設定（`prefers-reduced-motion`）のときは、場も形も止まる（問いは押したときだけ出る）。
記録の面にいるとき・喋っている最中・アプリを閉じているあいだは、描画そのものを止める。

## 色

**紙と墨だけ。** 地は温かい白（`#F4F2EE`）、字と形は墨（`#14120F`）。
色で差を付けず、濃さ・大きさ・余白で差を付ける。
ember（黒地）や aloud と並べたときに、ひと目で違う面だと分かる地にしてある。

## ロゴ

平らなアメーバを、脈が1本斜めに貫く。**脈はアメーバの中では地の色に反転する。**
声（かたち）と、その中に走っている筋（洞察）を、線1本で重ねた形。
`tools/make-icons.py` の生成物で、記録面の見出しにも同じ図形を置いている。

アイコンの絵を変えるときは、**必ずファイル名の `v` を上げる**
（iOS Safari は URL ごとに長期キャッシュするので、同じ名前のままでは古い絵が残る）。

## 右の面（記録）

面はこの順で、上から下へ**1本の背骨**になっている。

```
[ ロゴ  journaling                    ▢  ··· ]   ← 見出し（動かない）
[ 4 days   3 in a row   7 tags              ]
[ #洞察 #洞察 #洞察 …                       ]   ← 横に1行で流す
[ 0    6    12    18    24 ]────────────────    ← 時刻の目盛り（据え置き）
   2026年9月                                     ← 月の区切り
   今日 9/10 ────────────────────  まだ
   昨日 9/9  ──●───────○──────○     3
     07:12  まとめ…  #洞察
     13:40  まとめ…
   — 3日 —
   2026年8月
```

見出し・数・#タグ・目盛りは動かない（据え置き）。スクロールするのは日の帯だけ。
**目盛りと帯は左右の端をそろえてある**ので、上の数字がそのまま下の点の時刻になる。

**日ごとの帯**。上に時刻の目盛り（0・6・12・18・24）を1本だけ置き、
その下に日を新しい順に積む。1日が1本の線で、書いた時刻の位置に点が乗る。

- **1日に何度でも書ける前提**。点が増えていくことが、その日の線を見れば分かる
  （2件以上ある日は、右端に件数を出す）
- 点は **●=保存した / ○=まだ**。整形中の点はゆっくり点滅する
- 線の下に、その日の日記を時刻順に並べる（時刻・まとめ・`#洞察`・状態）。
  点でも行でも、押せば開く
- **書かなかった日は1行にまとめる**（`— 3日 —`）。詰めて並べると間が空いたことが見えず、
  1日1行で並べると空白ばかりになるため
- `#タグ` で絞ると、そのタグを持つ日だけが残り、該当する点に輪が付く
- **月をまたぐと区切りが入る**（`2026年9月`）。長くなったときの背骨
- **今日まだ書いていない日も、空の線と `まだ` を出す**。空いた1本があることが、書く理由になる

## うつす（copy）

日記はこの端末の中にしか無いので、外へ出す道をひとつだけ持たせている。

- 記録面の右上の **`▢`**：全部を1つの文にしてクリップボードへ（押すと `▢` が塗りつぶしになる）
- ひらいた1件の右上の **`▢`**：その1件だけ
- **各段の右上の `▢`**：`summary` / `origin` / `raw` を、その段だけ
- 中身は **要点 / 話したこと / 喋ったまま** の全部。日付と時刻と入口の語も付く
- `navigator.clipboard` は https か localhost でしか使えないので、
  使えないときは選択して写す昔の道（`execCommand`）に落ちる

## 設定（`···`）

毎日見るものではないものを、日記の並びから外に出すためだけの面。中身は2つだけ。

| | |
|---|---|
| `copy` | 日記を全部うつす（読める文で） |
| `data` | いま何件か・どこに置いているか・何で消えるか |
| `export` | まるごと写す（あとで戻せる形） |
| `import` | 貼って足し合わせる（上書きしない） |

以前ここに `key`（Claude の鍵）と `ask ai`（AIに読ませる文）があったが、
**鍵の概念も、AIに渡す口も、アプリからは外した**。写すのは `▢` だけで足りる。

## 1件の面（3段）

**記録に徹する。** 解釈は置かない。1件をひらくと、上からこの3つだけ。
各段の右上に **`▢`** があり、その段だけを写せる。

| 段 | 中身 | なぜこの形か |
|---|---|---|
| `summary` | **構造化した要点**。行を語で寄せて、かたまりごとに空きを入れる（最大6行前後） | だらだら喋ったものが、読み返せる形になって返ってくる。ここだけ読めば足りる |
| `#タグ` | その日の語（2つまで） | 記録を後から引くための取っ手。絞り込みに使う |
| `origin` | **ほぼ言ったまま、日本語だけ直した全行** | 一次情報。要点で落ちた行もここに残る |
| `raw` | 喋った文字そのまま。**畳んである**（`+` で開く） | 読むためではなく、消さないための段。あとから何にでも戻せる |

- `summary` の**見出し**は、そのかたまりで2回以上・3字以上出てくる語があるときだけ付ける。
  1回だけの語を見出しにすると「行抜」のような切れ端が出て、かえって読めなくなる（実際に出たのでやめた）
- `origin` は、**要点と同じ行しか無いときは出さない**（同じものを二度読ませない）
- 要約も言い換えもしない。言い換えると本人の言葉ではなくなる

### 置かなかったもの

洞察・気づきの抽出・過去との突き合わせ・問いの生成・AIへの受け渡しは、**全部やめた**。

規則で作れるのは並べ替えと拾い返しまでで、その先（矛盾の指摘、前提のすり替えの発見）は解釈。
規則で解釈したふりをすると外れる。外れたものが1つ混ざると、
当たっている記録のほうも信じられなくなる。だから記録だけを持つ。

写した文を自分でAIに渡すのは、いつでもできる（`▢` がその口）。

## 使う

### 手元で見る

```bash
python3 -m http.server 8930 --directory "vein"
```

`http://localhost:8930/` を開く。

### iPhone に置く（本命）

**https://wonleekorea-lab.github.io/vein/**

上のURLを Safari で開き、共有メニューから「ホーム画面に追加」。
`manifest.json` と `sw.js` があるので、追加後はアドレスバーのない全画面で立ち上がり、
オフラインでも起動する（Sokugan / 好きの種 と同じ形）。ホーム画面の名前は `journaling`。

**https（または localhost）でないと動かない。** `file://` ではキーボードのマイクも
Service Worker も使えない。

### 配信

`wonleekorea-lab/vein` の `main` ブランチ直下を GitHub Pages がそのまま配信する。
`git push origin main` すれば1〜2分で反映される。`.nojekyll` があるのでビルドは走らない。

## 音声

**Web Speech API は使わない。**声は iOS キーボードのマイクキー（Apple のディクテーション）から入れる。
理由は好きの種と同じで、Web Speech API では ①起動のたびにマイクの許可を訊かれ ②開始と終了に音が鳴る。
どちらも iOS 側が出すもので、API からは止められない。

- **音声ファイルは保存も送信もしない**。アプリが受け取るのは確定した文字だけ
- 打っても喋っても同じ欄に入る。喋れない場所ではそのまま打てばいい
- キーボードの高さは `visualViewport` で測り、`--kb` としてページ下の余白に入れる（`100dvh` はキーボードに反応しない）

### 長い文の見せ方

だらだら喋るので、**読ませる字ではなく「入っている」ことが見える字**にしている。
全体が一度に目に入るところまで自分で縮める（20px → 下限 8px）。

実測: 477字で16px、2120字で8px（このとき上が35pxだけ切れ、末尾が見える位置に留まる）。
上端はグラデーションで薄くしてあり、続きが上にあることだけ分かる。

## 組み立て（鍵はいらない）

**AIを呼ばない。鍵（API key）の概念を置かない。外へは何も送らない。**
やっているのは2つだけ。

| | やり方 |
|---|---|
| 行に割る（`origin`） | 句点で割り、頭の言いよどみ（えーと・なんか・で・あと…）を落とし、短い言い直しは前の行にくっつける |
| 要点にする（`summary`） | 行を語で寄せてかたまりにし、かたまりの中は言い方の重み（気づいた・つまり・結局・重要・やめ・決め…）と長さで残す。話した順は変えない |

タグは語の切り出し（2回以上出る長い語ほど強い）。分類名ではないので、
`#仕事` のような箱にはならない。**記録を後から引くための取っ手**として置いている。

sh "vein/build.sh"

`tools/make-icons.py` の `VERSION` → `shell-head.html` → `manifest.json` → `sw.js` の `CACHE` 名まで揃える。

## データ（溜まり続けるための仕組み）

日記は溜まり続けるものなので、**1か所に置かない**。

| 置き場 | 役割 |
|---|---|
| `localStorage`（`murmur_state_v1`） | 本体。すぐ読める |
| `IndexedDB`（`vein` / `state`） | 同じものの控え。iOS では localStorage より消されにくい |
| `murmur_snap_YYYY-MM-DD` | 日ごとの控え。直近10日ぶん（その日の最初の保存で1つ残す） |

**立ち上げのたびに全部を突き合わせて、足し合わせたものを本体にする。**
どれか1つが消えても残りから戻り、戻したときは「控えから N件を戻した」と出る。
読めないデータがあっても捨てず、`murmur_state_v1_backup_<時刻>` へ退避してから足し合わせる。
`navigator.storage.persist()` で端末に「消さないで」と頼む（断られても動きは変わらない）。

足し合わせの規則: 同じ `id` は**先へ進んでいるほう**（`kept` > `read` > `draft`、
同じなら行数・字数の多いほう）を残す。だから**何度足しても増えない**。

### それでも消えるとき

置き場を増やしても、**入れ物ごと**消える場合がある。ここは仕組みでは防げない。

- **ホーム画面のアイコンを削除して追加し直す**（iOS はアイコンごとに入れ物を持つ）
- Safari で開いたときと、ホーム画面から開いたときで**入れ物が別になる**ことがある
- Safari の「履歴とWebサイトデータを消去」／端末の入れ替え

そのための持ち出し口が設定（`···`）の **`export` / `import`**。

- `export`: 日記・タグ・出した問いまで、全部が1つの文字列になる。メモ帳などに貼って残す
- `import`: 貼って「足し合わせる」。**上書きではない**ので、何度貼っても増えない

**アイコンを入れ直す前・端末を替える前は、必ず `export` を取る。**

1件の形:

```
{ id, createdAt, day, seed, ask,     // seed = 入口の語（または問いの分類）
  raw, lines[], digest, tags[],      // ask  = 深い問いから始めたときだけ、その問い
  status }                            // draft → read → kept
```

設定（`settings`）は `seen`（出した問い）・`prev`（前の巡の順番）・`persisted` だけを持つ。

`summary`（かたまり分け）は保存しない。ひらくたびに組み立てる。
規則を直せば、過去の日記の見え方もその場で直る。

`picks` / `asks` / `notes` は旧版（Claudeを呼んでいたころ）の名残。
画面には出さないが、`▢` の写しにだけ「洞察（旧版）」として残す（消さないため）。

`status` は `draft`（置いたばかり）→ `read`（ひらいた）→ `kept`（`keep` を押した）。
`kept` になったものだけがタグの数（`tags`）に入る。

### 消えない仕組みの実測

| 試したこと | 結果 |
|---|---|
| `localStorage` だけ全部消して開き直す | 3件とも戻る（IndexedDB から。「控えから 3件を戻した」と表示） |
| `localStorage` も `IndexedDB` も消す → `import` に貼る | 2件とも戻る（「2件を足した」） |
| 同じものをもう一度 `import` | 増えない（「新しいものは無かった」） |

## ことば

画面まわりの語は**英単語1語**に統一する（好きの種と同じ規則）。日本語は、ユーザー自身の声と、
失敗の説明だけに残す。

| 語 | 意味 |
|---|---|
| `press` | 最初の一押し |
| `up` | 次の問いへ（深い問いの層） |
| `keep` | 置く（喋り終えて／読み終えて） |
| `close` | 閉じる |
| `clear` | 書きかけを消す |
| `forget` | この日記をそっと消す |
| `summary` / `origin` / `raw` | 構造化した要点 / ほぼ言ったままの全行 / 喋った文字そのまま |
| `days` / `in a row` / `tags` | 日数 / 連続 / タグの数 |
| `undo` / `yes` / `retry` | 通知の中の一手 |

## このMVPでやっていないこと

- 検索、クラウド同期、アカウント
- 見出しの手直し・統合（似た概念が別タグで増えたときにまとめる手段がない）
- 週・月のまとめ（溜まった日記を横断して読む面）
- 深い問いの絞り込み（「この系統だけ出す」「この問いはもう出さない」）
- 問いに答えた日記から、その系統だけを後で読み返す面
- リマインド（夜に「今日を喋る？」と促す通知）
- 音声の保存、Web Speech API による自前の文字起こし
- **AIによる解釈**（洞察の生成・要約・事実の追加）。記録に徹すると決めた

## 既知の制約

- 2000字を超えると 8px でも収まりきらず、上が少し切れる（末尾が見える位置に留まる）
- `summary` は語の一致で寄せるので、同じ話を別の言い方で喋った行は別のかたまりになる
- 見出しが付かない日も多い（2回以上出る語が無い日）。そのときは空きだけで切り替わりを見せる
- 語の並びは重なりを完全には避けられない。押し合わせているだけなので、ときどき一瞬すれ違う（実測1.7%）
- 語は漂っているので、押すのに少し狙いが要る（当たり判定は字のまわり12pxまで広げてある）
- 帯は今日から最も古い日まで全部の日を見るので、間が空きすぎると空き行の計算が長くなる（500日で打ち切る）
